# Web Dev Mini Projects

Small front-end projects I built while learning web development, collected in one place. Each folder is self-contained.

**Live gallery:** https://parakh20.github.io/web-dev-mini-projects/

| Project | Stack | What it is | Demo |
|---|---|---|---|
| [entroscope](entroscope/) | HTML, CSS, JS, Three.js | Interactive 3D model viewer for Entroscope by Entropeeps ("See entropy. Hear entropy.") | [open](https://parakh20.github.io/web-dev-mini-projects/entroscope/) |
| [agentforge-builder](agentforge-builder/) | HTML, CSS, JS | AgentForge prototype: build and simulate simple AI agents in the browser | [open](https://parakh20.github.io/web-dev-mini-projects/agentforge-builder/) |
| [agentforge-pitch-deck](agentforge-pitch-deck/) | HTML, CSS, JS, charts | Web pitch deck for AgentForge with market, ROI and financial projection charts | [open](https://parakh20.github.io/web-dev-mini-projects/agentforge-pitch-deck/) |
| [iitb-journey](iitb-journey/) | HTML, CSS, JS | Personal site about my first year at IIT Bombay | [open](https://parakh20.github.io/web-dev-mini-projects/iitb-journey/) |
| [task-manager-vanilla](task-manager-vanilla/) | HTML, CSS, JS | Task manager with dashboard, stats and local storage | [open](https://parakh20.github.io/web-dev-mini-projects/task-manager-vanilla/) |
| [bmi-calculator](bmi-calculator/) | HTML, CSS, JS | BMI calculator | [open](https://parakh20.github.io/web-dev-mini-projects/bmi-calculator/) |
| [bmi-calculator-react](bmi-calculator-react/) | React 18 | Same BMI calculator rebuilt in React | `npm install && npm start` |

## Running locally

Static projects: open the folder's `index.html` in a browser.

React project:

```bash
cd bmi-calculator-react
npm install
npm start
```

These projects used to live in separate repositories (`BMI-Calculator`, `bmi-calci-react`, `todo_manager`, `IITB-Journey-Website`, `agentforge_mvp`, `Agentforge_PitchDesk`, `Entroscope`) and were merged here to keep my profile tidy.
